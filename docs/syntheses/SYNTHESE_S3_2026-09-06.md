## En une phrase

Un convive qui ouvre le lien du QR (jeton opaque) voit le **menu du restaurant rattaché à sa table** — sans compte, en lecture seule. L’équipe interne peut créer des tables et **télécharger le QR PNG**.

---

## Ce qui a été livré

- Admin : créer / lister des tables ; télécharger `qr.png` (URL `https://…/t/<jeton>`).
- Public : `GET /t/<jeton>/menu` — restaurant, libellé de table, catégories, produits **disponibles**, photos, prix (centimes), options.
- Interface téléphone : page `/t/[token]` (menu lisible).
- Jeton inconnu ou table inactive → menu introuvable (404).
- Tests automatisés (API + affichage menu).

Pas encore : panier ni passage de commande (S4).

---

## Comment vérifier

1. Admin → restaurant → créer une table (ex. 14) → **QR PNG**.
2. Ouvrir le lien du QR, ou `http://localhost:3000/t/<jeton>`.
3. Vérifier : nom du restaurant, « Table 14 », produits et prix.
