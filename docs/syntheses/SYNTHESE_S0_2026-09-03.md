## Ce qui a été livré

## Comment vérifier (si tu as le dépôt)

```bash

curl -s http://localhost:8000/health
# → {"status":"ok"}
```

Arrêt : `docker compose down` (la base n’est pas encore remplie ; on peut l’éteindre sans perdre de menu).
