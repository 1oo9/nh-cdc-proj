## En une phrase

Notre équipe peut maintenant **se connecter** à une interface d’admin et **créer / modifier** catégories, produits (prix en centimes, disponibilité, photos en URL) et options — sans espace restaurateur.

---

## Ce qui a été livré

- Connexion admin (JWT) : `POST /admin/login`
- CRUD API protégé : restaurants, catégories, produits, groupes d’options, options
- Interface web minimale : `/admin/login`, liste des restaurants, fiche menu
- Seed démo mis à jour : admin interne prêt pour la démo locale
- Tests automatisés (API + formulaire de login)

Pas encore : génération de QR, menu public téléphone (S3), commande (S4).

---

## Accès démo (machine de dev)

- URL admin : [http://localhost:3000/admin/login](http://localhost:3000/admin/login)
- Identifiants seed : `admin@nh.example` / `nh-admin`  
  (compte **interne** uniquement — pas un compte restaurateur)
