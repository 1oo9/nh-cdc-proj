## En une phrase

Une nouvelle commande (ou un changement de statut) **apparaît sur la tablette cuisine sans rafraîchir** ; si le Wi‑Fi coupe la socket, un **polling 5 s** prend le relais.

---

## Ce qui a été livré

- Canal Redis `kitchen:{restaurant}` : événement à la création de commande et à chaque avance de statut.
- WebSocket cuisine authentifié (jeton PIN) : ` /kitchen/ws `.
- Reconnexion automatique côté tablette.
- Repli : rechargement automatique toutes les 5 secondes + bouton Rafraîchir.
- Tests automatisés (publish, WS, poll).

---

## Comment vérifier

1. Ouvrir `http://localhost:3000/cuisine` (PIN `nh-kitchen`).
2. Sur un téléphone / autre onglet : passer une commande via `/t/<jeton>`.
3. Le ticket doit apparaître **sans** cliquer Rafraîchir (sinon attendre ≤ 5 s).
